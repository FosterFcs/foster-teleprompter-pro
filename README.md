# Foster Teleprompter V0.2
Versão de teste com prévia de câmera, alternância frontal/traseira, teleprompter e gravação local via MediaRecorder.

**Importante:** câmera e microfone normalmente exigem HTTPS (por exemplo, GitHub Pages) ou localhost. Abrir o HTML diretamente como `file://` pode bloquear a câmera. A gravação é exportada em WebM; compatibilidade de reprodução depende do aparelho/navegador.

Para testar: publique em HTTPS, abra no Chrome Android, autorize câmera e microfone, ative a câmera, teste leitura e gravação e toque em “Baixar vídeo gravado”.
